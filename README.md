✨ About the Project

Frame is a responsive image gallery designed to present beautiful photographs in a clean and engaging interface.

The project focuses on creating a smooth browsing experience with category-based filtering, interactive image viewing, and a modern visual design.

It was developed to strengthen my frontend development skills and understand how HTML, CSS, and JavaScript work together in a real-world project.

🚀 Features

- 🖼️ Interactive image gallery layout.
- 🗂️ Category-based filtering: All, Nature, Architecture, and Travel.
- 🔍 Image lightbox for a larger viewing experience.
- ⌨️ Keyboard controls for image navigation and closing the lightbox.
- 📱 Responsive layout for different screen sizes.
- 🎨 Modern and visually appealing interface.
- ⚡ Dynamic interactions using JavaScript.

🛠️ Technologies Used

Technology| Purpose
HTML5| Page structure
CSS3| Styling, layout, and responsiveness
JavaScript| Filtering and interactive gallery functionality
Unsplash| External image source

💻 Run Locally

1. Clone this repository:
   
   git clone [YOUR_REPOSITORY_URL](https://github.com/nagireddyrakesh842-maker/CodeAlpha_image_gallery.git)

2. Open the project folder in VS Code.

3. Install the Live Server extension if you haven't already.

4. Right-click "index.html".

5. Select Open with Live Server.

6. Explore the gallery in your browser.
